# Agent Werewolves

LLM agents play Werewolf at one table so you can watch, measure, and compare how different models bluff and reason. React Router v8 (SSR) app running on Cloudflare Workers.

Production: https://agent-werewolves.witkos4.workers.dev

Platform decision and operational details: [`context/foundation/infrastructure.md`](context/foundation/infrastructure.md).

## Develop

Requires Node `>=22.22.0`.

```bash
npm install
npm run dev   # http://localhost:5173, runs in the Workers runtime
npm test      # Workers-runtime tests; never call the network
```

Local vars and secrets go in `.dev.vars` (gitignored):

| Name | Purpose |
| --- | --- |
| `APP_ENV` | `development` |
| `OPENROUTER_API_KEY` | OpenRouter key the game room calls models with |
| `SPIKE_KEY` | Value of the `x-spike-key` header that unlocks `/api/spike/*` (any random string) |

## Typecheck and build

```bash
npm run typecheck   # regenerates worker-configuration.d.ts + route types, then tsc
npm run build
npm run preview     # serve the production build locally
```

`worker-configuration.d.ts` is generated by `wrangler types` (`npm run cf-typegen`) and gitignored; rerun it after changing `wrangler.jsonc`.

## Deploy

- **Automatic:** every push to `main` runs `.github/workflows/ci.yml`. It typechecks, builds, deploys, then smoke-tests `/healthz`. PRs run the same checks plus `wrangler deploy --dry-run`, without deploying.
- **Manual:** `npm run deploy` (needs `npx wrangler login` or the env vars below).

## Health

```bash
curl https://agent-werewolves.witkos4.workers.dev/healthz
# {"status":"ok","environment":"production","version":{"id":"…","tag":"","timestamp":"…"}}
```

`version.id` is the live Worker version; compare with `npx wrangler deployments list`.

## Logs

```bash
npx wrangler tail agent-werewolves
```

Past requests are in the Cloudflare dashboard: Workers & Pages → agent-werewolves → Logs.

## Rollback

CI never rolls back on its own. A failed deploy turns the run red and prints these steps. A human runs:

```bash
npx wrangler deployments list
npx wrangler rollback <previous-version-id>
```

Then check `/healthz` reports that version. To roll forward, re-run the latest `main` workflow or `npm run deploy`.
